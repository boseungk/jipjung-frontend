# 프로젝트 개요

## 프로젝트명
jipjung-frontend (집-중 프론트엔드)

## 프로젝트 목적
SSAFYHome Lifestyle Showroom - 감성 우선(Emotional-First) 대시보드 애플리케이션

## 핵심 컨셉
"감성이 먼저, 기능은 그 다음" 철학을 따르는 Vue 3 기반 라이프스타일 쇼룸 대시보드

## 주요 특징
- **감성 우선 디자인**: Crystal Ball 비주얼을 중심으로 사용자의 꿈의 집을 시각화
- **게이미피케이션**: 레벨 시스템, 경험치, 연속 저축 스트릭 등으로 동기 부여
- **하이브리드 디자인 시스템**: 
  - Neumorphism (Day 모드): 부드러운 입체 효과
  - Glassmorphism (Night 모드): 반투명 유리 효과
- **4가지 컬러 테마**: Warm Beige, Olive Green, Cool Gray, Sky Blue
- **인터랙티브 효과**: 눈 내리는 효과, 마우스 반응형 조명, Day/Night 전환

## 정보 우선순위
1. Crystal Ball (꿈의 시각화) - 감성
2. 달성률 (Achievement) - 동기
3. 게이미피케이션 - 재미
4. 데이터 (통계, DSR) - 이성
5. 드림홈 상세 - 정보

## 현재 상태
- Mock 데이터로 프로토타입 완성
- 향후 백엔드 API 연동 예정
- Chart.js 기반 저축 통계 차트 구현 대기 중
