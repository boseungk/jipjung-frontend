  ---
  🎨 주요 기능

  1. 반응형 레이아웃

  - Desktop (≥1040px): 50/50 좌우 분할
  - Tablet (768-1039px): 40/60 좌우 분할
  - Mobile (<768px): 300px 지도 + 스크롤 목록 (상하 스택)

  2. 카카오맵 통합

  - CustomOverlay로 이모지 마커 표시
  - 호버 시 InfoWindow 툴팁
  - 클릭 시 매물 선택 및 상세 정보 표시
  - 자동 바운드 조정 (모든 마커 표시)

  3. 마커 색상 코딩

  - 🟢  초록: 구매 가능 (계약금 ≤ 보유 금액)
  - 🔴 빨강: 고가 (계약금 > 보유 금액)
  - 🟠  코랄: 선택된 매물

  4. 매물 필터

  - 지역 선택 (시/도, 구/군)
  - 가격 범위
  - 매물 유형 (아파트, 빌라, 오피스텔)
  - 면적 범위

  5. Dream Home 연동

  - "내 집으로 설정" 버튼 → dreamHomeStore 업데이트
  - Toast 알림 후 대시보드로 자동 이동
  - 대시보드에서 저축 진행 상황 확인

  6. 사용자 경험

  - Glassmorphism 디자인 일관성
  - Day/Night 테마 자동 대응
  - 로딩/Empty 상태 UI
  - Toast 알림 시스템
