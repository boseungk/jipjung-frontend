📌 프로젝트 개요

서비스 정의

부동산 데이터 기반으로 현실적인 '내 집' 목표를 설정하고, 게이미피케이션을 통해 저축 습관을 형성하는 금융 동기부여 플랫폼입니다.

핵심 변경 사항 (v2.0 → v3.0)

컨셉 변경: '나무 키우기(Grome)' → '집 짓기 & 방 꾸미기 (Jip-joong)'

진행 모델: 레벨업 시스템 → Phase 1(공사) & Phase 2(인테리어) 2단계 구조 도입

디자인 시스템: 3-Way 하이브리드 디자인(뉴모피즘+글래스모피즘+미니멀리즘) 및 Night 모드 조명 시스템 도입

대상 사용자

Core Target: 내 집 마련의 꿈은 있지만, 당장 거대한 목표액에 압도되어 저축 동기를 잃은 2030 세대

Pain Point: "3억을 언제 모아?"라는 막막함

Solution: "일단 10만원 모아서 기초 공사부터 끝내자"라는 마이크로 목표(First Milestone) 제시

🔄 핵심 UX 프로세스 (The First Milestone)

이 서비스는 단일 루프가 아닌, 두 단계의 순차적 경험을 제공합니다.

Phase 1: 온보딩 & 첫 집 짓기 (Construction)

목표: 사용자의 이탈을 방지하고 '첫 성취감'을 빠르게 제공

행동: 가입 후 '첫 마일스톤(예: 10만원)' 저축

시각화: 청사진(Blueprint) → 기초 공사 → 골조 완성 → 외관 완공

보상: 완공 시 Phase 2(쇼룸) 잠금 해제 연출 (Grand Opening)

Phase 2: 메인 게임 & 꿈의 방 꾸미기 (Interior)

목표: 장기적인 저축 습관 유지 (Long-term Retention)

행동: 월 저축 목표 달성, 추가 저축 미션 수행

시각화: 텅 빈 쇼룸 → 가구 배치 → 완성된 인테리어

보상: 저축액에 따라 고퀄리티 가구 아이템 획득 (수집 욕구 자극)

🎯 기능별 요구사항

우선순위 표기

[P1] SHOULD: 차별화 기능

1. 회원 관리 & 목표 설정

[P0] REQ-1.1 온보딩 및 청사진(Blueprint) 생성

설명: 사용자 정보를 입력받아 DSR을 계산하고, 목표 주택의 '청사진'을 생성하는 과정
입력:

연소득, 기존 대출, 희망 지역 (기존 동일)

추가: '첫 마일스톤' 금액 설정 (기본값: 10만원 ~ 100만원 사이 추천)
출력:

생성된 청사진 화면: "OO님만의 집이 설계되었습니다. 이제 기초 공사를 시작해볼까요?"
제약조건:

DSR 규제(스트레스 DSR 3단계) 반영된 한도 계산 필수

2. Phase 1: 집 짓기 (게이미피케이션 Part 1)

[P0] REQ-2.1 공사 진행률 시각화

설명: '첫 마일스톤' 목표 금액 대비 현재 저축액 비율에 따라 집의 공사 단계가 변화
입력: 저축 기록 (saving_records)
로직:

0% ~ 20%: 터 닦기 & 안전 펜스

20% ~ 50%: 골조(프레임) 공사

50% ~ 80%: 외벽 & 지붕 공사

100%: 완공 (Exterior 완성)
출력:

단계별 SVG/Lottie 애니메이션

[P0] REQ-2.2 완공 및 Phase 전환 (Unveiling)

설명: Phase 1 달성 시, 극적인 연출과 함께 Phase 2로 전환
트리거: 첫 마일스톤 100% 달성 시
연출:

공사 가림막 제거 또는 커튼이 걷히는 애니메이션

"나만의 쇼룸 오픈!" 메시지

UI 테마 변경: 공사판(거친 느낌) → 럭셔리 쇼룸(글래스모피즘)

3. Phase 2: 방 꾸미기 (게이미피케이션 Part 2)

[P0] REQ-3.1 쇼룸(Showroom) 대시보드

설명: 사용자의 메인 홈 화면. 3D 아이소메트릭 뷰로 방 내부를 보여줌
기능:

회전/줌인 불가 (고정 뷰, 디자인 퀄리티 유지)

획득한 가구 자동/수동 배치

Day/Night 모드 토글에 따른 조명 효과 변화

[P0] REQ-3.2 가구 아이템 상점/보상 시스템

설명: 저축 달성도에 따라 가구를 획득하거나 구매
획득 조건:

기본 가구: 월 목표 저축 달성 시 지급

레어 가구: 연속 저축(Streak) 달성, 특판 상품 가입 시 지급

컬렉션: 테마별 가구 세트 (모던, 클래식, 내추럴 등)
데이터: furniture_items, user_inventory

4. 부동산 & 금융 (Core Logic)

[P0] REQ-4.1 구매력 기반 매물 추천 (기존 유지)

설명: Phase 2의 '창문' 밖 풍경이나 목표 설정에 실제 매물 정보 연동
기능:

사용자가 설정한 목표 매물(드림홈)의 시세 변동 정보를 주기적으로 업데이트

시세 상승/하락에 따른 "목표 달성까지 D-Day" 자동 재계산

[P0] REQ-4.2 저축 기록 및 피드백

설명: 저축 입력 시 즉각적인 시각적 피드백 제공
UX Flow:

금액 입력 & 저축하기 버튼 클릭 (뉴모피즘 인터랙션)

동전이 쇼룸 저금통으로 들어가는 효과 또는 게이지가 차오르는 효과

목표 달성 시 "새로운 소파가 도착했습니다!" 알림

5. UI/UX 디자인 요구사항 (New & Critical)

본 프로젝트의 핵심 경쟁력은 '심미적 만족감'에 있으므로, 아래 디자인 요구사항을 엄격히 준수해야 합니다.

[P0] UI-1. 하이브리드 디자인 시스템 적용

설명: 요소의 역할에 따라 3가지 스타일을 명확히 구분하여 적용

상호작용 요소 (버튼, 카드): 뉴모피즘 (Neumorphism)

듀얼 쉐도우 (Light/Dark) 필수

클릭 시 inset 쉐도우로 '눌리는 느낌' 구현

시각적 요소 (쇼룸 컨테이너): 글래스모피즘 (Glassmorphism)

backdrop-filter: blur 사용

반투명 보더로 고급스러운 유리 질감 표현

정보 텍스트: 미니멀리즘 (Minimalism)

장식을 배제하고 가독성 최우선 (Noto Sans KR)

[P0] UI-2. Day & Night 조명 시스템 (Atmosphere)

설명: 시간대 또는 사용자 토글에 따라 쇼룸의 분위기를 완전히 반전

Day Mode:

따뜻한 베이지(Warm Beige) 톤 배경

자연광 중심, 선명한 그림자

Night Mode:

어두운 차콜/브라운 톤 배경

7-Layer 조명 시스템 활성화 (Ambient, Lamp, Window, Spotlight 등)

CSS mix-blend-mode 등을 활용한 은은한 발광 효과

[P1] UI-3. 마이크로 인터랙션

버튼: 호버 시 미세한 빛반사(Shimmer) 효과

전환: Phase 1 → 2 전환 시 끊김 없는(Seamless) 애니메이션

로딩: 단순 스피너 대신 '집이 지어지는' 또는 '가구 조립 중' 애니메이션 사용

6. 비기능 요구사항 (NFR)

성능 (Performance)

NFR-1: CSS 애니메이션 및 backdrop-filter 사용 시 GPU 가속(transform: translateZ(0))을 활용하여 모바일에서도 60fps 유지

NFR-2: 3D/SVG 에셋은 경량화(SVGO 등 사용)하여 초기 로딩 속도 1.5초 이내 달성

데이터 무결성 (Integrity)

NFR-3: 사용자의 저축 기록 수정/삭제 시, 이미 지급된 '가구 아이템' 회수 로직(또는 패널티) 구현 필요 (게이미피케이션 어뷰징 방지)

✅ 마일스톤 수정안

Sprint 1: Core & Phase 1 (2주)

회원가입/로그인 & DSR 온보딩

디자인 시스템 구축 (Tailwind 설정, 뉴모피즘/글래스모피즘 유틸리티)

Phase 1 (공사 중) 화면 및 게이지 연동

Sprint 2: Phase 2 & Game Loop (2주)

가구 아이템 데이터베이스 구축 및 저축 보상 연동

Sprint 3: Polish & Real Data (2주)

국토부 실거래가 API 연동 및 드림홈 시세 업데이트

최종 버그 수정 및 배포
