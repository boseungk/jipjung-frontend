## 요약

| 항목 | 내용 |
|------|------|
| **테스트 일시** | 2025-12-17 |
| **테스트 시나리오** | G1, G2, G3, G6 (4개 완료) |

### 핵심 결론

게이미피케이션 요소(XP, 레벨, 스트릭, 집 짓기)는 **시각적으로 잘 구현**되어 있으나, **초보자가 이해하기 어려운 부분**이 많습니다. 특히 각 요소가 무엇을 의미하는지, 어떻게 획득하는지에 대한 **설명이 부족**합니다.

## 시나리오별 상세 분석

### G1: 드림홈 목표 설정

#### 플로우 다이어그램
```
대시보드 진입
    ↓
GoalGuideModal 자동 표시
    ↓
"매물 보러가기" 클릭
    ↓
/properties 이동 (지도 + 리스트)
    ↓
매물 클릭 → 상세 패널 슬라이드
    ↓
"내 집으로 설정" 클릭
    ↓
Step 1/2: 테마 선택 (3가지)
    ↓
Step 2/2: 목표 금액/기간 설정
    ↓
대시보드 반영 (토스트 메시지)
```

#### 단계별 소요시간

| 단계 | 화면 | 소요시간 | 비고 |
|------|------|---------|------|
| 1 | 대시보드 진입 | 즉시 | GoalGuideModal 자동 표시 |
| 2 | GoalGuideModal 확인 | - | CTA 명확 ("매물 보러가기") |
| 3 | 매물 목록 이동 | 1초 미만 | 지도 + 리스트 동시 표시 |
| 4 | 매물 상세 클릭 | 즉시 | 상세 패널 슬라이드 |
| 5 | "내 집으로 설정" 클릭 | - | 2단계 모달 시작 |
| 6 | 테마 선택 (Step 1/2) | - | 3가지 테마 선택 가능 |
| 7 | 목표 설정 (Step 2/2) | - | 금액/기간 자동 계산 |
| 8 | 대시보드 반영 확인 | 즉시 | 토스트 메시지 표시 |

#### 발견된 이슈
- **[C1]** 목표 금액이 "21900원"으로 표시 (실제: 2억 1900만원)
- **[M2]** GoalGuideModal 닫은 후 재호출 방법 없음
- **[M3]** 테마 선택 시 중간 단계 미리보기 없음

### G2: 저축 및 XP 획득

#### 플로우 다이어그램
```
대시보드 → "저축하기" 버튼 클릭
    ↓
SavingInputModal 표시
    ↓
금액 입력 (예: 50,000원)
    ↓
"저축하기" 실행 (API 호출)
    ↓
"+5 XP 획득!" 토스트 표시
    ↓
대시보드 업데이트 (XP 바, 자산 그래프)
```

#### 단계별 소요시간

| 단계 | 화면 | 소요시간 | 비고 |
|------|------|---------|------|
| 1 | "저축하기" 버튼 클릭 | 즉시 | SavingInputModal 표시 |
| 2 | 금액 입력 (50,000원) | - | 숫자 입력만 가능 |
| 3 | 저축 기록 완료 | 1초 미만 | API 호출 |
| 4 | XP 획득 피드백 | 즉시 | "+5 XP 획득!" 토스트 |
| 5 | 대시보드 업데이트 | 즉시 | XP 바, 자산 그래프 갱신 |

#### 발견된 이슈
- **[H1]** XP가 무엇인지 설명 없음
- **[H3]** 저축 전 예상 XP 미표시
- **[M4]** XP 바 증가 애니메이션 없음

### 평가 기준 (5점 만점)

| 점수 | 이해도 | 동기부여 | 피드백 품질 | 밸런스 |
|------|--------|----------|-------------|--------|
| 5 | 별도 설명 없이 즉시 이해 | 매일 사용하고 싶음 | 만족스러운 시각/청각 피드백 | 노력 대비 보상 적절 |
| 4 | 1회 사용 후 이해 | 자주 확인하고 싶음 | 적절한 피드백 | 대체로 균형 잡힘 |
| 3 | 설명을 읽으면 이해 | 가끔 흥미로움 | 기본적인 피드백 | 약간 조정 필요 |
| 2 | 설명을 읽어도 혼란 | 별 관심 없음 | 피드백 부족 | 밸런스 문제 있음 |
| 1 | 전혀 이해 불가 | 오히려 방해됨 | 피드백 없음 | 심각한 불균형 |

### 요소별 상세 분석

#### XP 시스템 (종합 3.0)
- **이해도 2점**: XP가 무엇인지, 어떻게 얻는지 설명 없음
- **동기부여 3점**: 숫자 증가는 흥미롭지만 의미 불명확
- **피드백 3점**: 토스트 메시지는 있지만 애니메이션 부족
- **밸런스 4점**: 1만원당 1XP는 적절한 비율

#### 레벨 시스템 (종합 2.75)
- **이해도 2점**: "터파기 건축가"의 의미 불명확
- **동기부여 3점**: 레벨업 욕구는 있지만 혜택 불명확
- **피드백 2점**: 레벨업 시 축하 피드백 미확인 (G5 미테스트)
- **밸런스 4점**: 100XP로 레벨업은 적절한 난이도

#### 스트릭 (종합 3.75) ⭐ 최고 점수
- **이해도 3점**: 불꽃 그리드는 직관적이나 조건 불명확
- **동기부여 4점**: 연속 기록 유지 욕구 자극
- **피드백 4점**: 빨간/노란 불꽃 시각적 구분 명확
- **밸런스 4점**: 7일 주기는 적절함

#### 집 짓기 단계 (종합 3.3)
- **이해도 3점**: 6단계 진행은 이해하나 조건 불명확
- **동기부여 4점**: 집이 완성되어가는 시각적 만족감
