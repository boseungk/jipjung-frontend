카카오 JavaScript 키 설정 방법

  - 루트에 .env.local 파일을 만들고 다음 한 줄을 넣어요:
      - VITE_KAKAO_MAP_KEY=여기에_발급받은_Javascript_키
  - 키는 카카오 디벨로퍼스 → 내 애플리케이션 → 앱 키 → JavaScript 키를 복사해 사용하세요.
  - 카카오 디벨로퍼스 → 내 애플리케이션 → 플랫폼 → Web 플랫폼에서 허용 도메인에 개발 주소를 등록하세요. 예:
      - http://localhost:5173
      - http://127.0.0.1:5173
        (실제 배포 호스트가 있다면 그것도 추가)
  - 개발 서버 재시작 후(npm run dev) 지도 로딩을 확인합니다.
